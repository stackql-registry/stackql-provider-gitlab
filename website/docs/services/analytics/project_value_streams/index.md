Value streams available to the project. Generated from the GitLab GraphQL schema field Project.valueStreams (connection of ValueStream nodes).

```sql
SELECT
id,
name,
namespace
FROM gitlab.analytics.project_value_streams
WHERE full_path = '{{ full_path }}' -- required
AND host = '{{ host }}' -- required (defaults to gitlab.com; or set GITLAB_HOST)
AND id = '{{ id }}'
;
```
