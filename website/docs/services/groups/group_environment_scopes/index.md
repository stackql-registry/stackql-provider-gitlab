Environment scopes of the group. Generated from the GitLab GraphQL schema field Group.environmentScopes (connection of CiGroupEnvironmentScope nodes).

```sql
SELECT
name
FROM gitlab.groups.group_environment_scopes
WHERE full_path = '{{ full_path }}' -- required
AND host = '{{ host }}' -- required (defaults to gitlab.com; or set GITLAB_HOST)
AND name = '{{ name }}'
AND search = '{{ search }}'
;
```
