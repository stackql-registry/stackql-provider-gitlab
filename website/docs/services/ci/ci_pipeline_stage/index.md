Stage belonging to a CI pipeline. Generated from the GitLab GraphQL schema field Query.ciPipelineStage (CiStage).

```sql
SELECT
id,
name,
status
FROM gitlab.ci.ci_pipeline_stage
WHERE id = '{{ id }}' -- required
AND host = '{{ host }}' -- required (defaults to gitlab.com; or set GITLAB_HOST)
;
```
